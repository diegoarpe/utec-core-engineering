# File Handling

Ejercicios y ejemplos sobre operaciones de entrada/salida (I/O) con archivos en Python.

## Contenido

| Archivo | Descripción |
| --- | --- |
| `read_file.py` | Función que lee un archivo de texto UTF-8 e imprime su contenido en stdout |
| `main.py` | Script principal que importa y ejecuta la función `read_file()` |
| `my_file_0.txt` | Archivo de texto de ejemplo para pruebas |
