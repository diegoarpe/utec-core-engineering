# Control Flow

Estructuras de control en Python: condicionales, bucles y manejo del flujo de ejecución.

## Temas

| Tema | Descripción |
| --- | --- |
| Condicionales | Toma de decisiones con `if`, `elif` y `else` |
| Bucles `for` | Iteración sobre secuencias y rangos con `range()` |
| Bucles `while` | Repetición mientras se cumpla una condición |
| `break` / `continue` | Control del flujo dentro de los bucles |
