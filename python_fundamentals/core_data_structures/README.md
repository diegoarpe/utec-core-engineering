# Core Data Structures

Estructuras de datos básicas de Python: listas, tuplas, diccionarios y conjuntos.

## Temas

| Tema | Descripción |
| --- | --- |
| Listas | Colecciones ordenadas y mutables: indexación, slicing y métodos como `append()` y `remove()` |
| Tuplas | Colecciones ordenadas e inmutables |
| Diccionarios | Pares clave-valor con acceso rápido por clave |
| Conjuntos (`set`) | Colecciones sin elementos repetidos y operaciones de conjuntos |
| Iteración | Recorrer estructuras con `for` |

## Archivos

| Archivo | Descripción |
| --- | --- |
| `print_list_integer.py` | Imprime una lista de enteros |

## Cómo ejecutar

```bash
python3 <archivo>.py
```
