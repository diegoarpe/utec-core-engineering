# Exception Handling

Manejo de excepciones en Python: captura de errores, bloques try-except, y control de flujo ante excepciones.

## Temas

| Tema | Descripción |
| --- | --- |
| Try-Except | Captura y manejo básico de excepciones |
| Múltiples excepciones | Manejo de diferentes tipos de errores |
| Else en excepciones | Código que se ejecuta si NO hay excepción |
| Finally | Código que siempre se ejecuta (limpieza de recursos) |
| Excepciones personalizadas | Crear y lanzar tus propias excepciones |
| Raise | Lanzar excepciones manualmente |

## Archivos

| Archivo | Descripción |
| --- | --- |
| `safe_print_list.py` | Imprimir elementos de una lista de forma segura |

## Cómo ejecutar

```bash
python3 <archivo>.py
```

## Conceptos clave

- **Try**: Bloque de código que puede generar excepciones
- **Except**: Captura y maneja excepciones específicas
- **Else**: Se ejecuta si no hay excepciones en try
- **Finally**: Se ejecuta siempre, incluso si hay excepciones
- **Raise**: Lanza excepciones manualmente
