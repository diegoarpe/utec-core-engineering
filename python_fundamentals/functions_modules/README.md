# Functions & Modules

Funciones y módulos en Python: cómo definir bloques de código reutilizables y organizarlos en archivos.

## Temas

| Tema | Descripción |
| --- | --- |
| Funciones | Definición con `def`, parámetros y valores de retorno con `return` |
| Argumentos | Posicionales, por nombre (`kwargs`), valores por defecto y `*args` / `**kwargs` |
| Alcance (scope) | Variables locales y globales |
| Módulos | Importar código con `import` y `from ... import ...` |
| Librería estándar | Uso de módulos incluidos como `math` y `random` |

## Archivos

| Archivo | Descripción |
| --- | --- |
| _Pendiente_ | Aún no hay ejercicios en esta carpeta |

## Cómo ejecutar

```bash
python3 <archivo>.py
```
