# Classes and Object Model

Clases y modelo de objetos en Python: cómo definir clases, crear instancias y cómo Python organiza objetos, atributos y métodos.

## Temas

| Tema | Descripción |
| --- | --- |
| Clases | Definición con `class` y creación de instancias |
| Atributos y métodos | Atributos de instancia y de clase, métodos y `self` |
| Método `__init__` | Inicialización de objetos |
| Métodos especiales | Métodos dunder como `__str__` y `__repr__` |
| Herencia | Reutilización de código con clases base y clases derivadas |
| Encapsulamiento | Convenciones para atributos privados y propiedades (`@property`) |
