# Inheritance

Herencia en Python: cómo una clase derivada reutiliza y extiende el comportamiento de una clase base.

## Temas

| Tema | Descripción |
| --- | --- |
| Herencia simple | Definir una clase derivada con `class Hija(Base)` |
| `super()` | Llamar al método de la clase base desde la clase derivada |
| Sobrescritura (*override*) | Redefinir un método heredado en la clase hija |
| `isinstance` e `issubclass` | Comprobar si un objeto o una clase pertenece a una jerarquía |
| Herencia múltiple | Heredar de varias clases y orden de resolución de métodos (MRO) |
| Atributos heredados | Cómo los atributos privados (`__atributo`) se resuelven en cada clase |
